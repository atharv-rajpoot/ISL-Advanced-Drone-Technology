# ISL Advanced Drone Technology

## 📌 About the Project

This repository contains my project work completed as part of the **Virtual Internship with Indian Space Lab (ISL)**. The project focuses on concepts related to **advanced drone technology, control systems, autonomous navigation, and simulation-based analysis**.

The work explores how feedback and control techniques can be applied to autonomous aerial and marine vehicles under different operating conditions.

## 🚁 Key Topics Covered

* **PID Control Systems** — implementation and analysis of proportional, integral, and derivative control.
* **Drone Altitude & Attitude Control** — simulation of controlled drone movement.
* **Wind Disturbance Analysis** — studying the effect of external disturbances on vehicle stability.
* **Trajectory Tracking** — following predefined paths using control algorithms.
* **Figure-Eight Trajectory** — simulation of drone tracking along a complex trajectory.
* **Autonomous Boat Guidance** — exploration of guidance and path-following concepts for autonomous marine vehicles.
* **Control System Visualization** — graphical analysis of system responses and simulation results.

## 🛠️ Technologies Used

## 🎯 Objectives

The primary objectives of this project are to:

1. Understand fundamental drone control and guidance concepts.
2. Implement PID-based control simulations.
3. Analyze the effect of disturbances on autonomous systems.
4. Study trajectory and path-tracking techniques.
5. Visualize and interpret simulation results.
6. Develop practical understanding of autonomous vehicle control systems.

## 📊 Project Outcomes

The simulations provide a practical understanding of how control algorithms influence the stability, accuracy, and trajectory-following performance of autonomous systems.

This project helped strengthen my knowledge of **Python-based simulation, feedback control, PID tuning, autonomous navigation, and robotics-related concepts**.
